## 风险与待确认

- 店小秘真实页面 DOM 可能与模拟页不同，需要在用户登录环境中做二次选择器校准。
- 速卖通真实订单页可能使用虚拟列表或动态字段，需要以非敏感 DOM 结构更新 adapter 和 fixture。
- 各销售平台开放 API 与认证字段未确认，商品上架第一版仅保留目标平台/店铺入口。
- 系统推荐的数据来源未确认，现有代码主要是模拟推荐。
