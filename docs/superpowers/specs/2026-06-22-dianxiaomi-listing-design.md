# 店小秘优先的商品采集上架营销系统设计

## 背景

本项目已有 FastAPI 后端、Jinja 页面、SQLite 数据库、Next.js 前端雏形和 Chrome 浏览器插件雏形。第一版目标是优先完成“采集商品、处理图片/营销信息、通过店小秘半自动上传”的可用闭环，并参考用户提供的两张界面图：

- 系统端参考：类似“跨境商品 AI 上架助手”的商品工作台，支持店铺选择、批量处理、图片进度、问题提示和一键写入。
- 插件端参考：类似店小秘页面内“商品同步助手”的浮层，支持 SKU/变种识别、快捷筛选、全选/反选、上传开关和同步进度。

第一版不优先做速卖通、Ozon、Joom、Shopify 的真实直传。销售平台名称保留在 UI 和后续扩展入口中，但真实上传优先围绕店小秘浏览器登录态和插件半自动同步。

## 已确认决策

- 第一版采用“真实对接店小秘优先”的方向。
- 店小秘对接方式采用浏览器登录态/半自动上传，不要求第一版调用店小秘开放 API。
- 第一版同时做系统工作台入口和店小秘页面内插件浮层，优先保证店小秘浮层体验。
- 技术路线采用方案 A：复用现有 `backend/` FastAPI/Jinja 页面，增强 `browser-plugin/`，暂不迁移到 Next 前端。
- 系统推荐、输入商品链接、浏览器插件三种采集方式都保留。

## 范围

### 第一版包含

- 系统端商品工作台：店铺选择、采集步骤条、筛选、批量选择、图片进度、问题提示、AI 处理/补图/写入操作。
- 三种采集入口：系统推荐、输入商品链接、浏览器插件导入。
- 本地商品状态闭环：已采集、处理中、处理完成、待插件同步、同步中、已写入、失败。
- 店小秘页面内插件浮层：SKU/变种识别、快捷筛选、全选/反选、已选数量、变种列表、上传开关、采集/同步按钮、进度展示。
- 插件与本地后端通信：拉取待同步商品，回写同步进度和成功/失败结果。
- 错误提示和重试入口：系统端列表展示可行动的问题提示，插件端展示识别/填充失败原因。

### 第一版不包含

- 速卖通、Ozon、Joom、Shopify 的真实直传。
- 店小秘开放 API 的直接服务端调用。
- 完整后台任务队列或分布式任务调度。
- Next.js 前端替换现有 Jinja 页面。

## 架构

### 后端系统工作台

继续使用 `backend/` 中的 FastAPI + Jinja 页面作为主界面。重点改造商品、采集和上架相关页面，使其形成一个接近参考图的统一工作台：

- 顶部显示写入目的地和店小秘店铺选择。
- 操作区包含 AI 处理、参考图、一键补图、一键写入店小秘等动作。
- 步骤条表达“采集商品、AI 处理、确认结果、移入待发布”的主流程。
- 列表展示商品图片、标题、来源、负责人、采集时间、状态、图片进度、问题提示和操作按钮。
- 筛选条件包含搜索、来源、状态、问题。

后端接口负责采集、商品管理、状态更新、准备店小秘同步和插件回写。

### 本地数据与任务状态

继续使用 SQLite + SQLAlchemy。第一版尽量复用 `Product`、`CollectionRecord`、`ListingRecord`、`CollectionTask` 和 `PlatformAccount`，只补必要字段或用 JSON 承载扩展信息。

推荐在 `Product` 上补充：

- `owner`：负责人。
- `target_store`：目标店小秘店铺。
- `image_progress`：图片处理进度，如 `{ "done": 6, "total": 6, "stage": "图片已生成" }`。
- `issue_message`：问题提示。
- `sync_payload`：插件写入店小秘所需结构化数据。
- `sync_status`：`none`、`pending`、`syncing`、`success`、`failed`。
- `sync_error`：同步失败原因。

写入记录继续使用 `ListingRecord`，第一版建议 `platform=dianxiaomi` 且 `via_dianxiaomi=true`，因为真实动作发生在店小秘页面内。

### 浏览器插件

插件保留现有 popup 采集入口，同时新增对店小秘页面的 content script 支持：

- 在店小秘页面注入右侧或悬浮面板。
- 自动识别当前页面 SKU/变种信息。
- 从本地系统拉取待写入商品。
- 尝试把标题、图片、价格、变种等字段填入店小秘页面。
- 将进度、成功或失败结果回写本地后端。

如果店小秘页面 DOM 不稳定，插件保守降级为辅助模式：展示已识别字段、缺失字段、复制按钮、打开商品详情或提示用户确认，不让流程卡死。

### 销售平台直传

速卖通、Ozon、Joom、Shopify 在界面中作为后续扩展保留。现有直传服务里明显阻塞问题需要最小修复，避免影响页面操作，但不作为第一版核心验收。

## 关键用户流程

### 系统工作台批量流程

1. 用户进入系统工作台。
2. 用户选择写入目的地和店小秘店铺。
3. 用户通过系统推荐、商品链接或浏览器插件采集商品。
4. 商品进入统一列表，状态为 `collected`。
5. 用户按来源、状态、问题筛选商品。
6. 用户批量选择商品，执行 AI 处理或一键补图。
7. 商品图片进度从 `0/6` 更新到 `6/6`，状态变为 `processed`。
8. 用户执行一键写入店小秘。
9. 后端将商品标记为 `sync_pending`，等待店小秘页面内插件同步。

### 店小秘页面内插件流程

1. 用户打开店小秘页面并保持登录。
2. 插件注入“商品同步助手”浮层。
3. 浮层识别当前页面 SKU/变种并展示快捷筛选标签。
4. 用户全选、反选或勾选具体变种。
5. 用户开启“上传到店小秘”开关。
6. 用户点击采集/同步按钮。
7. 插件从本地系统拉取 `sync_pending` 商品。
8. 插件匹配当前页面 SKU/变种，填充商品信息或提供辅助复制/确认。
9. 插件回写同步进度。
10. 同步成功后，后端更新商品为 `listed` 或 `sync_status=success`；失败则记录 `sync_error` 并展示问题提示。

### 系统与插件联动

系统端“一键写入店小秘”不直接调用店小秘 API，而是创建本地待同步状态。插件在店小秘页面中读取待同步商品，执行半自动写入，并回写进度和结果。

## 状态定义

推荐扩展 `Product.status`：

- `collected`：已采集，待处理。
- `processing`：AI/图片处理中。
- `processed`：处理完成，可写入。
- `sync_pending`：等待插件写入店小秘。
- `syncing`：插件正在写入。
- `listed`：已写入或上架成功。
- `failed`：处理或写入失败。

插件侧维护：

- 当前店小秘页面识别到的 SKU/变种。
- 已选 SKU/变种。
- 当前同步商品 ID。
- 图片/字段写入进度。
- 用户是否开启“上传到店小秘”。

## API 设计

新增或补齐以下接口：

- `POST /api/products/process`：批量 AI 处理或补图，更新图片进度和状态。
- `POST /api/products/sync/dianxiaomi/prepare`：系统端一键写入，把商品标记为待插件同步。
- `GET /api/plugin/dianxiaomi/pending`：插件获取待写入商品。
- `POST /api/plugin/dianxiaomi/progress`：插件回写当前写入进度。
- `POST /api/plugin/dianxiaomi/result`：插件回写成功或失败结果。
- `GET /api/plugin/dianxiaomi/status`：浮层展示本地服务状态和统计。

现有接口继续保留：

- `POST /api/products/collect/by-url`
- `POST /api/products/collect/by-plugin`
- `POST /api/products/collect/recommend`
- `POST /api/products/collect/recommend/import`
- 商品列表、编辑、删除接口。

## 错误处理

系统端列表通过“问题提示”展示可行动错误：

- 采集失败：链接不可访问、解析不到标题或图片、来源平台未知。
- 图片不足：展示可补图数量或图片生成进度。
- 待同步：展示“等待店小秘插件同步”。
- 插件未连接：提示用户打开店小秘页面并启用插件浮层。
- 店小秘页面识别失败：插件提示未识别 SKU/变种，并提供刷新或重新识别。
- 字段填充失败：插件记录失败字段并回写后端，系统展示摘要。
- 同步失败：`ListingRecord` 保存错误详情，商品允许重试。

## 验证方式

- 后端验证：运行已有测试或最小接口 smoke test，覆盖商品列表、批量处理、准备同步、插件拉取、插件回写。
- 页面验证：启动后端页面，检查工作台列表、筛选、批量选择、状态进度和写入按钮没有脚本错误。
- 插件验证：检查 Manifest、popup/content 脚本语法；在店小秘域名匹配规则下能注入浮层，并能访问本地后端。
- 店小秘受限时的验证：使用本地或静态 DOM 模拟页验证 SKU/变种识别、浮层交互和回写流程。

## 验收标准

- 系统端有接近参考图 03 的商品工作台：店铺选择、步骤条、批量列表、筛选、图片进度、问题提示、AI 处理/补图/写入操作。
- 支持系统推荐、输入链接、浏览器插件导入三种采集入口。
- 用户可以在系统端选择商品并标记为待写入店小秘。
- 店小秘页面内插件浮层接近参考图 04：SKU 识别、快捷筛选、全选/反选、已选数量、变种列表、上传开关、采集/同步按钮、进度展示。
- 插件可以从本地系统拉取待同步商品，并把进度、成功、失败回写系统。
- 销售平台直传保留入口但明确为后续扩展，不影响店小秘主流程。
